# alensi-pay
Payment Processing Platform

A standalone payment platform focused purely on moving money.

Demonstrates:

Payment initiation
M-Pesa / mobile-money integration
Payment provider abstraction
Webhooks & callbacks
Transaction lifecycle
Idempotency
Retries & failure handling
Refunds
Payment status tracking
API authentication
Audit logging

Stack: Java, Spring Boot, PostgreSQL, Redis, RabbitMQ, Docker
